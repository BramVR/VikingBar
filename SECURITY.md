# Report a security issue

Email `bram.van.rompuy@gmail.com` with the affected version or commit, reproduction steps, and expected impact. Do not include account passwords, tokens, invoices, or raw Mobile Vikings responses.

Keep suspected vulnerabilities out of public issues until a fix or disclosure plan is agreed. Report ordinary bugs through [GitHub issues](https://github.com/BramVR/VikingBar/issues) with synthetic or redacted examples.

VikingBar is a development project. Security fixes target `main`; older development builds have no separate maintenance branch. Builds are not Developer ID signed or notarized.
